以 **Godot 4 / GDScript** 打造的回合制歐洲戰爭六角格戰棋,聚焦 **14–18 世紀**:百年戰爭的長弓與騎士、義大利戰爭的火繩槍方陣、三十年戰爭的線列火槍與野砲、路易十四與大北方戰爭的騎兵突擊。

架構與開發流程參考姊妹專案 **WorldWarII**:決定性六角戰鬥、資料驅動的兵種/地形/劇本、無頭 GDScript 測試與靜態資料驗證。

## 這是什麼

一款緊湊的戰術戰棋,重點在**決定性六角戰鬥**、地形壓力、戰爭迷霧與視線、壓制與士氣/潰散、老兵經驗與歷史將領加成。專案刻意做成**資料驅動**:兵種、地形、將領、劇本都以 JSON 存放於 `data/`,GDScript 負責規則、畫面流程與 UI 行為。

同一個位置、HP、地形與加成,永遠得到相同的戰鬥結果——玩家與 AI 共用 `CombatRules` 的攻擊合法性判定,戰損不會漂移。

## 遊玩流程

主選單 → 單次作戰(選難度)→ 作戰簡報(**選擇陣營**)→ **部署(指派將領)** → 戰鬥 → 結果。

**選擇陣營**:不必固定扮演歷史主角方。單次作戰於簡報選擇要指揮的一方(攻或守),AI 接手另一方;戰役則於選戰役後選定一方,整場沿用、老兵沿該方延續。玩家選防守側時,AI 進攻方會自動轉為積極進攻。

**部署**:開戰前為每支部隊指派歷史將領(每位限一支、僅適用對應兵種),加成於戰鬥生效;有部署區的劇本仍在戰場上擺位。

**征服(多勢力歐陸霸權)**:主選單 →「征服」→ 進入橫跨**歐洲、北非、西亞**的大戰略地圖(**可平移/縮放**:WASD/中鍵拖曳、滾輪縮放)。**七大強權**在圖上彼此攻伐,你執掌**法蘭西**。地圖節點分兩型:**城市**(方形)是補給點與存亡命脈,可**徵兵**(招募老兵入名冊)與**整補**(晉升老兵);**資源點**(菱形)每回合供輸國力。**戰略層是多勢力,戰術戰仍是兩方**——每場戰鬥沿用該領地的劇本當中立棋盤(攻方 vs 守方)。

- **回合流程**:你每回合可攻打一塊相鄰、且與己方**有補給城市**相連的敵方領地(親臨戰術戰),並花國力於整軍/工業/訓練/徵兵/整補/戰前準備;按**結束回合**後,各 AI 強權依序出兵。**AI 之間的戰事以數值自動判定**(不開戰場,結果列於「上回合列強動向」);AI 對**你**的進攻則進入**防守佇列**,由你親臨迎戰(防守換邊鏡像:你指揮該劇本守方、AI 進攻)。
- **難度**(開局於地圖右上角選定並鎖定):簡單/普通/困難縮放列強 AI 的軍備上限、每回合收入、出兵積極度與**是否設防**。AI 會以餘裕國力為前線城市加築工事;你強攻已設防的敵城時,守軍同樣帶著該地工事迎戰。
- **外交停戰**:選取某強權領地可花國力締結數回合**互不侵犯**——期間你不能進攻對方、對方 AI 也不反攻你(仍與他國交戰),到期自動失效。用來穩住一線、集中兵力於另一線。積分列以 `☮N` 標示。
- **補給網(每勢力)**:每個勢力的補給自其**擁有的城市**沿己方領地鏈供輸;被切斷的領地不產國力、不能當進攻跳板/設防。地圖綠線為補給線,斷補領地轉暗。
- **存亡**:一個勢力**失去所有城市即出局**(其殘餘領地歸征服者)。你失去所有城市即**帝國覆滅**;成為**最後屹立的強權**即一統歐陸。
- **養成**:存活部隊帶老兵經驗編入下一場征服戰鬥(空缺以該地預設兵員補足),城市徵兵/整補讓你穩定壯大軍隊。戰前準備(偵察/砲擊/補給)與設防工事會流進下場戰術戰的開局。

地圖與勢力定義於 `data/conquest.json`(`powers[]` + 領地 `type`/`yield`);另附小型 `continental`(雙強權)與確定性 `test_arena`。

**科技(全域)**:主選單 →「科技研發」進入**全域科技樹**。研發點數為**跨模式共用的單一池**——單次作戰、戰役、征服的每場勝利(含次要目標)都進帳——並**持久化存檔**(`user://progress.json`),重開遊戲仍在。解鎖科技為全軍相應兵種提供**永久加成**(攻擊/防禦/破甲/移動/視野),於**所有模式**生效;科技間有前置關係,定義於 `data/techs.json`。戰役的**整備室**亦提供同一科技樹的入口。

**戰役**:主選單 →「戰役」→ 選戰役 → **選擇陣營** → **整備室** → 簡報 → 部署 → 戰鬥。存活部隊帶著老兵經驗進入下一場(戰間回復滿血),戰敗可重試本場。在**整備室**可查看倖存名冊、花研發點數**晉升**老兵(+1 階),並進入全域「科技研發」。現有十個戰役:「百年戰爭:英格蘭遠征」(克雷西 → 阿金庫爾)、「義大利戰爭:火與矛」(切里尼奧拉 → 拉文納 → 馬里尼亞諾 → 比科卡 → 帕維亞)、「三十年戰爭:北方雄獅」(布萊登費爾德 → 呂岑 → 訥德林根)、「英國內戰:議會軍的崛起」(埃奇山 → 馬斯頓荒原 → 納斯比)、「火藥的時代」(帕維亞 → 布萊登費爾德 → 羅克魯瓦 → 布倫海姆)、「大北方戰爭:彼得的崛起」(納爾瓦 → 列斯納亞 → 波爾塔瓦)、「西班牙王位繼承戰爭:馬爾博羅的征程」(布倫海姆 → 拉米伊 → 奧德納爾德 → 馬爾普拉凱)、「奧地利王位繼承戰爭:西里西亞的崛起」(莫爾維茨 → 霍亨弗里德貝格 → 索爾)、「七年戰爭:腓特烈的考驗」(羅斯巴赫 → 洛伊滕 → 庫勒斯多夫)、「歐陸大會戰:1314–1759」(依年代串接全部 28 場歷史會戰)。戰役定義於 `data/campaigns.json`,新增只需列出有序的劇本 `id`。

## 系統概要

**戰鬥公式**

```text
base   = max(1, attack + vs_armor(若目標披甲) - defense - terrain_defense - dig_in)
damage = max(1, round(base * attacker_hp / attacker_max_hp))
```

- `armor` 代表重甲/馬鎧(騎士、憲兵重騎、重裝步兵);`vs_armor` 是長矛、戟與火砲穿甲的加成——這正是帕維亞的核心。
- 傷害隨攻擊方當前 HP 縮放:見血的隊伍打得更軟。
- 防守方若存活、攻擊方在其射程內、且自身可反擊(臼砲/野砲等砲組不能反擊),則發動**減半反擊**。

**機制**

- 戰爭迷霧與六角視線(敵軍會遮擋視野)。
- 管制區(ZoC):貼近敵軍會增加移動成本;被壓制的單位停止投射 ZoC。
- **壓制與士氣/潰散**:非致命打擊施加壓制並消耗士氣;高壓制會降低移動與攻擊。被夾擊(相鄰敵軍)會降低抵抗;士氣歸零則**潰散**,自動後撤且無法指揮,直到重整。
- **整隊(R)**:降低壓制、恢復士氣,可把潰散單位拉回;掩蔽地形恢復更多。
- **構築工事(E)**:消耗行動提升野戰工事,增加防禦(工兵與間接火力可拆除)。
- **嚴陣以待(O)**:預備射擊——敵軍進入射程時給予反應攻擊。
- **老兵經驗**:作戰中累積 XP 升階,提升攻/防/移動/視野與士氣上限。
- **歷史將領**:對特定兵種提供加成(如黑太子強化長弓與下馬騎士、孔代親王強化騎兵衝鋒)。
- 砲兵:野砲為直射火力,需要視線且不能反擊;臼砲為間接火力,無視視線遮擋且有濺射傷害。
- 拋射(長弓/弩,`arcing`):可越過**己方**單位對可見目標射擊(箭矢拋物線),但**敵方**單位與遮擋地形仍會阻斷;平射的火繩槍/火槍需要清空射界。

**AI**:決定性評分 AI,對每個可行動單位評估移動落點——落地攻擊價值(擊殺高權重)為主導,曝險微調走位。推進權重只在「該落點尚無法攻擊」時生效(已進入射程就不再盲目逼近),遠程單位(射程 ≥2)偏好從最大射程開火而非貼臉。除逐單位評分外,AI 具**陣營級思考**(每回合開始由劇本勝利條件推導):**目標壓力**(奪取本方 `capture`/`control_count` 目標格、據守須否決敵方的目標格,領先時加碼推進以終結)、**淺層先讀**(落點若會被下回合合計火力擊殺,依單位價值為交換定價——為擊殺而戰死划算、僅為蹭傷送死則否決)、**協調/集中**(友軍相鄰加分,鼓勵集火、抑制孤軍深入)。每個陣營可設 `posture`(`balanced`/`defensive`/`aggressive`)——防守傾向重視掩蔽、避免曝險、固守不躁進。難度為權重階梯(進取、反擊迴避、部隊保存、目標追擊、交換否決、集中與簡單難度的走位失誤預算),困難最積極、簡單最保守;`test_selfplay` 以對稱演武場鏡像對局斷言難度階梯單調(`hard>easy`)。

## 專案結構

```text
data/       JSON 兵種、地形、將領、劇本
scenes/     Godot 場景(主選單、選劇本、簡報、戰鬥)
scripts/    autoload、六角格、單位、戰鬥、回合/AI、劇本、UI
tests/      無頭 GDScript 測試
tools/      驗證器與資料檢查
assets/     字型(Noto Sans CJK TC,SIL OFL 1.1)
```

字型:內建 Noto Sans CJK TC 作為預設主題字型與 `ThemeDB.fallback_font`,讓中文在任何機器上都能顯示(含單位字符與六角標籤)。

## 執行

```bash
cd Eu-War
godot --path .          # 主場景 res://scenes/main_menu.tscn
```

首次執行請先讓 Godot 匯入資源(開啟編輯器一次,或 `godot --headless --import .`),否則字型不會被匯入。

## 驗證

```bash
tools/validate_fast.sh   # 不啟動 Godot:引擎版本閘、JSON、Python 編譯、資料驗證
tools/validate.sh        # 上述 + 全部無頭 GDScript 測試
```

`tools/validate.sh` 執行:

- Godot 4.2 專案特徵閘(`config/features` 未漂移)。
- 全部 JSON 語法檢查與 `tools/validate_data.py`(未知參照、地圖矩形、越界/不可通行/重複座標的部署、佔領目標、將領 `applies_to`)。
- Python 編譯檢查。

## 新增劇本

完整規範見 **[docs/SCENARIO_STANDARD.md](docs/SCENARIO_STANDARD.md)**(史實配置、選邊、勝利條件、工事/破陣、戰役/征服整合、驗證流程)。速覽:

1. 複製 `data/scenarios/` 中的一個 JSON,改 `id`(與檔名一致)、`title`、`era`、`briefing`、`map`、`factions`、`units`、`victory`。
2. 座標使用 odd-r 偏移 `[col, row]`,執行期轉為軸向六角座標。
3. **恰好兩個陣營**:`factions[0]` 為歷史主角方(單場預設玩家),兩方皆可被選邊操控——故**雙方都要有可達成的 `victory`**。
4. **posture 依史實**:進攻方 `"aggressive"`、防守方 `"defensive"`(省略即 `"balanced"`)。有備而戰的防守方適度加 `dig_in`;若要能破深工事,攻方需配 `pioneers`/`mortar`(或刻意不配以還原史實)。
5. (可選)`deployment`(開戰前排陣區)、`reinforcements`(排程增援)、`secondary_objectives`(次要目標)、`tutorial`(分步教學提示)、歷史將領。
6. 併入戰役/征服:更新 `data/campaigns.json` / `data/conquest.json`。
7. 驗證:`tools/validate_fast.sh`(或 `validate.sh` 含全測試)+ `tools/balance_report.py --check`;`test_selfplay` 會自動涵蓋新劇本。劇本會自動出現在單次作戰列表。
