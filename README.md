# Eu-War 歐陸烽火

[![CI](https://github.com/Fischer-Zhang/EU-War/actions/workflows/ci.yml/badge.svg)](https://github.com/Fischer-Zhang/EU-War/actions/workflows/ci.yml)

🎮 **[線上試玩](https://fischer-zhang.github.io/EU-War/)** — 瀏覽器直接遊玩(Web 匯出)

以 **Godot 4 / GDScript** 打造的回合制歐洲戰爭六角格戰棋,聚焦 **14–18 世紀**:百年戰爭的長弓與騎士、義大利戰爭的火繩槍方陣、三十年戰爭的線列火槍與野砲、路易十四與大北方戰爭的騎兵突擊。

架構與開發流程參考姊妹專案 **WorldWarII**:決定性六角戰鬥、資料驅動的兵種/地形/劇本、無頭 GDScript 測試與靜態資料驗證。

## 這是什麼

一款緊湊的戰術戰棋,重點在**決定性六角戰鬥**、地形壓力、戰爭迷霧與視線、壓制與士氣/潰散、老兵經驗與歷史將領加成。專案刻意做成**資料驅動**:兵種、地形、將領、劇本都以 JSON 存放於 `data/`,GDScript 負責規則、畫面流程與 UI 行為。

同一個位置、HP、地形與加成,永遠得到相同的戰鬥結果——玩家與 AI 共用 `CombatRules` 的攻擊合法性判定,戰損不會漂移。

## 遊玩流程

主選單 → 單次作戰(選難度)→ 作戰簡報 → 戰鬥 → 結果。

**戰役**:主選單 →「戰役」→ 選擇一個戰役,依序打完多場串接的會戰。存活部隊會帶著累積的老兵經驗進入下一場(戰間回復滿血),戰敗可重試本場。每場勝利獲得**研發點數**,可在作戰簡報的「科技研發」畫面解鎖**科技樹**——為全軍相應兵種提供永久加成(攻擊/防禦/破甲/移動/視野),科技間有前置關係。科技定義於 `data/techs.json`。現有四個戰役:「百年戰爭:英格蘭遠征」(克雷西 → 阿金庫爾)、「義大利戰爭:火與矛」(馬里尼亞諾 → 帕維亞)、「火藥的時代」(帕維亞 → 布萊登費爾德 → 羅克魯瓦 → 布倫海姆)、「歐陸大會戰:1314–1709」(全部九場歷史會戰)。戰役定義於 `data/campaigns.json`,新增只需列出有序的劇本 `id`。

## 系統概要

**戰鬥公式**

```text
base   = max(1, attack + vs_armor(若目標披甲) - defense - terrain_defense - dig_in)
damage = max(1, round(base * attacker_hp / attacker_max_hp))
```

- `armor` 代表重甲/馬鎧(騎士、憲兵重騎、重裝步兵);`vs_armor` 是長矛、戟與火砲穿甲的加成——這正是帕維亞的核心。
- 傷害隨攻擊方當前 HP 縮放:見血的隊伍打得更軟。
- 防守方若存活、攻擊方在其射程內、且自身非間接火力(砲兵不能反擊白刃),則發動**減半反擊**。

**機制**

- 戰爭迷霧與六角視線(敵軍會遮擋視野)。
- 管制區(ZoC):貼近敵軍會增加移動成本;被壓制的單位停止投射 ZoC。
- **壓制與士氣/潰散**:非致命打擊施加壓制並消耗士氣,被夾擊(相鄰敵軍)會降低抵抗;士氣歸零則**潰散**,自動後撤且無法指揮,直到重整。
- **整隊(R)**:降低壓制、恢復士氣,可把潰散單位拉回;掩蔽地形恢復更多。
- **構築工事(E)**:消耗行動提升野戰工事,增加防禦(工兵與間接火力可拆除)。
- **嚴陣以待(O)**:預備射擊——敵軍進入射程時給予反應攻擊。
- **老兵經驗**:作戰中累積 XP 升階,提升攻/防/移動/視野與士氣上限。
- **歷史將領**:對特定兵種提供加成(如黑太子強化長弓與下馬騎士、孔代親王強化騎兵衝鋒)。
- 間接火力(野砲/臼砲)無視視線遮擋;臼砲有濺射傷害。

**AI**:決定性評分 AI,對每個可行動單位評估移動落點——落地攻擊價值(擊殺高權重)為主導,曝險微調走位。推進權重只在「該落點尚無法攻擊」時生效(已進入射程就不再盲目逼近),遠程單位(射程 ≥2)偏好從最大射程開火而非貼臉。每個陣營可設 `posture`(`balanced`/`defensive`/`aggressive`)——防守傾向重視掩蔽、避免曝險、固守不躁進。難度為權重階梯(進取、反擊迴避、部隊保存、推進與簡單難度的走位失誤預算),困難最積極、簡單最保守。

## 專案結構

```text
data/       JSON 兵種、地形、將領、劇本
scenes/     Godot 場景(主選單、選劇本、簡報、戰鬥)
scripts/    autoload、六角格、單位、戰鬥、回合/AI、劇本、UI
tests/      無頭 GDScript 測試
tools/      驗證器與資料檢查
assets/     字型(Noto Sans CJK TC,SIL OFL 1.1)
```

字型:內建 Noto Sans CJK TC 作為預設主題字型與 `ThemeDB.fallback_font`,讓中文在任何機器上都能顯示(含單位字符與六角標籤)。

## 執行

```bash
cd Eu-War
godot --path .          # 主場景 res://scenes/main_menu.tscn
```

首次執行請先讓 Godot 匯入資源(開啟編輯器一次,或 `godot --headless --import .`),否則字型不會被匯入。

## 驗證

```bash
tools/validate_fast.sh   # 不啟動 Godot:引擎版本閘、JSON、Python 編譯、資料驗證
tools/validate.sh        # 上述 + 全部無頭 GDScript 測試
```

`tools/validate.sh` 執行:

- Godot 4.2 專案特徵閘(`config/features` 未漂移)。
- 全部 JSON 語法檢查與 `tools/validate_data.py`(未知參照、地圖矩形、越界/不可通行/重複座標的部署、佔領目標、將領 `applies_to`)。
- Python 編譯檢查。
- `tests/run_all.sh` 的 6 個無頭 GDScript 測試,包含六角數學、戰鬥公式、尋路、佔領判定、資料完整性,以及載入全部畫面並實跑一回合困難 AI 戰鬥的 UI 冒煙測試。

## 新增劇本

1. 複製 `data/scenarios/` 中的一個 JSON。
2. 修改 `id`、`title`、`era`、`briefing`、`map`、`factions`、`units`、`victory`。
3. 座標使用 odd-r 偏移 `[col, row]`,執行期轉為軸向六角座標。
4. (可選)在 `factions[]` 加 `"posture"` 調整該陣營的 AI 傾向:`"balanced"`(預設)、`"defensive"`(重視掩蔽、避免曝險、固守不躁進——適合防守方)、`"aggressive"`(積極推進)。
5. (可選)加入 `deployment` 讓玩家在開戰前排陣:`"deployment": { "blue": { "cols": [0, 4], "rows": [0, 9] } }` —— 指定該陣營可部署的 odd-r 矩形範圍(含端點),戰鬥開始前玩家可在區內移動或互換己方部隊。省略則無部署階段。
6. (可選)`tutorial` 提供分步教學提示:字串或 `{ "text": "...", "advance_on": "move" }`,`advance_on` 可為單一動作或陣列(`select`/`move`/`attack_ranged`/`attack_melee`/`entrench`/`brace`/`rally`)。
7. 執行 `tools/validate_fast.sh`;劇本會自動出現在單次作戰列表。
